# Narrative patterns and selection rules

Use this reference only when structure selection or a difficult revision is central to the assignment. The author's original structures and seven plots are preserved without modification in [HOW_TO_STORYTELLING.md](HOW_TO_STORYTELLING.md).

## Identify the reader's question (Minto)

The original guide uses **BLOT → Situation → Complication → Resolution**. This remains the default visible business-story scaffold. Minto's documented planning formulation is **Situation → Complication → Question (SCQ)**, where the audience's question determines the answer and logical supporting groups. Distinguish an internal planning method from the finished communication:

1. **Situation:** What does this audience already accept as current reality?
2. **Complication:** What changed, is broken, constrained, surprising, or contested?
3. **Question:** What would a rational reader now need answered?
4. **Answer/BLOT:** What defensible response follows from the evidence?
5. **Support:** Organize the minimum necessary evidence into logically distinct groups; check whether each really supports the answer.

When writing to a time-constrained decision-maker, usually state the answer first, then give situation/complication and supporting logic. When the answer is not yet known, write the actual unresolved question, not an invented conclusion. Minto's source explicitly emphasizes identifying the reader's question and testing logical groupings; the exact presentation sequence is a skill design decision, not a quote from Minto.

## Choose according to reader and proof

| Pattern | Appropriate | Avoid |
| --- | --- | --- |
| BLOT / SCR (guide) with explicit SCQ planning | Board decision, funding or strategic case | Claim-first narrative before the claim is supportable |
| Hook → key points → takeaway (guide) | C-suite update; concise professional post | Forced 3–4 points when only one material fact exists |
| Hero's Journey (guide) | Genuine team journey, documented pivot, learning through failure | Manufacturing a protagonist, crisis, heroics, or resolution |
| Duarte's what-is / what-could-be contrast | Persuasive speech or change proposal | Describing aspirations as predictions or verified outcomes |
| Evidence → comparator → limitation → implication | Audit, incident review, scientific/technical finding, neutral analysis | Introducing drama just to meet a story template |
| Seven basic plots (guide) | Optional thematic frame when actual events strongly support it | Treating literary archetypes as empirical proof or a mandatory checklist |

## Compress and expand without losing meaning

- **One-line BLOT:** Audience-relevant claim + evidence qualifier or implication, if needed.
- **~3-minute:** BLOT → necessary context → one pivotal comparison/obstacle → evidence and uncertainty → decision/takeaway.
- **Long form:** Expand traceability, options, constraints, limitations, and decision trade-offs, not extra drama.

## Professional post heuristics

For factual thought leadership, the author may choose observation → tension → explanation → implication → genuine open question. Preserve a distinctive, technically accurate voice and reject engagement bait, rhetorical adversaries, made-up anecdotes, and forced calls for comments. If the user supplied a specific opening or catchphrase, preserve it unless asked to rewrite.

## Handling tensions between frameworks

- The guide suggests **3–4 visual chunks** and a one-line/three-minute reduction. Treat these as useful techniques when appropriate, not inviolable limits or compulsory appended output.
- The guide says to **not skip struggle**. Interpret that as not hiding a *real* complication when discussing transformation. Do not manufacture a struggle in a neutral report.
- The guide's seven plots are **creative organizational lenses**. They are not a scientific taxonomy demonstrating that every business report has one of seven structures.
